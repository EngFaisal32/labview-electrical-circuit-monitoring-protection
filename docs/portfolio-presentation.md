# Portfolio Presentation

## Project title

**Electrical Circuit Monitoring & Protection System Using LabVIEW**

Category: **Electrical Engineering | Automation & Instrumentation**  
Software: **NI LabVIEW 2020**  
Type: **Academic Engineering Project**

## Short description

Designed a LabVIEW-based software application to calculate and monitor electrical parameters in a four-resistor DC circuit. The interactive Front Panel displays calculated voltage, current, resistance and power and provides threshold-based warning/error indications. The project demonstrates principles of cyclic monitoring, conditional logic, alarm feedback and operator-interface design that are transferable to PLC/HMI work.

## Connection to industrial automation

The project applies concepts relevant to PLC and HMI engineering: parameter updates, threshold evaluation, operator indications, state control and fault messages. The implementation itself is in LabVIEW, with **no physical PLC or industrial HMI**.
